# LingvoQuest

## Created by Dias Zakir

### How to install

1. Clone repository to your local computer with command: `git clone https:github.com/diaszakir/LingvoQuest`
2. Create telegram-bot using `@BotFather` bot
3. Install MongoDB
4. Install packages: `pip install pyTelegramBotAPI pymongo requests python-dotenv`
5. Create .env file and write your token there
6. Use `words.csv` or create new .csv file with your own words and definitions
7. Launch the bot using command: `python bot.py`


### Languages:
Russian, but you can change any language
